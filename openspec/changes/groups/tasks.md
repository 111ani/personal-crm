# Tasks

Каждая задача с кодом приложения — по TDD (CLAUDE.md): сначала тест, запустить `pnpm test` и увидеть, что он красный, потом код, тест зелёный. Имя теста — название сценария из `specs/contact-groups/spec.md`. Перед `pnpm test` база должна быть запущена (`pnpm db:up`; Docker Desktop может быть выключен — сначала запустить его).
