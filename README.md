# Личная CRM

Приложение для своих контактов: кто это, откуда знакомы, телефон и почта, заметки о том, о чём договорились.

## Что умеет

- **Список контактов** — открываете приложение и сразу видите всех людей, по алфавиту
- **Поиск по имени** — начните печатать в строке поиска; слова можно писать в любом порядке: «Смирнова Анна» найдёт «Анна Смирнова»
- **Добавление контакта** — кнопка «Добавить контакт», обязательно только имя. Новый контакт подсвечивается в списке
- **Карточка контакта** — нажмите на человека в списке:
  - слева — заметки: напишите, о чём поговорили, и нажмите «Добавить заметку» (или Ctrl + Enter). Заметки хранятся с датой, новые сверху
  - справа — данные контакта: можно исправить и нажать «Сохранить изменения»
- Все данные хранятся в базе на сервере, поэтому в любом браузере по тому же адресу видны те же контакты

## Как запустить

Нужны: запущенный **Docker Desktop**, **Node.js** и **pnpm**.

1. Если файла `.env` нет — скопируйте `.env.example` в `.env` и заполните значения
2. Установите зависимости (один раз):

   ```
   pnpm install
   ```

3. Подготовьте базу (один раз): команда запустит PostgreSQL в Docker, создаст таблицы и заполнит базу 1000 тестовых контактов

   ```
   pnpm db:setup
   ```

4. Соберите приложение (заново — после каждого изменения кода):

   ```
   pnpm build
   ```

5. Запустите приложение:

   ```
   pnpm start
   ```

6. Откройте в браузере: http://localhost:3000

Остановить приложение — `Ctrl + C` в окне, где запущен `pnpm start`.

`pnpm dev` — режим разработки: сразу подхватывает правки в коде, но с 1000 контактов список открывается в десятки раз медленнее (около 15 секунд против 0,3). Для обычной работы с контактами используйте `pnpm build` + `pnpm start`.

## База данных

| Команда | Что делает |
| --- | --- |
| `pnpm db:up` | Запускает PostgreSQL в Docker и ждёт, пока база будет готова |
| `pnpm db:migrate` | Создаёт или обновляет таблицы по миграциям из папки `drizzle` |
| `pnpm db:seed` | Заполняет **пустую** базу 1000 тестовых контактов. Если контакты уже есть — ничего не меняет |
| `pnpm db:seed --reset` | **Удаляет все контакты и заметки** и заново заполняет базу тестовыми данными |
| `docker compose ps` | Проверить, что база работает — в колонке STATUS должно быть `healthy` |
| `docker compose stop` | Остановить базу. Данные при этом сохраняются |

Тестовые контакты вымышленные. Почтовые адреса — на зарезервированных доменах `example.com`, `example.org`, `example.net`: такие адреса не принадлежат реальным людям.

## Для разработчика

- Next.js 16 (App Router, Cache Components), TypeScript, React 19, Tailwind CSS 4, shadcn/ui (Base UI)
- PostgreSQL 18 в Docker, Drizzle ORM: схема — `src/db/schema.ts`, миграции — `drizzle/`
- Браузер к базе не обращается: чтение — в серверных компонентах (`src/lib/contacts/queries.ts`), изменения — через Server Actions (`src/app/actions.ts`)
- После изменения схемы: `pnpm db:generate` (создаст миграцию), затем `pnpm db:migrate`
- Проверки: `pnpm typecheck`, `pnpm lint`, `pnpm build`
